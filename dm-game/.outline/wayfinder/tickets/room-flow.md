# 방 생성·입장 흐름

## Question

방은 어떻게 만들고 들어가는가? (방 코드, 초대 링크) 닉네임을 받는가? 첫 보내는 사람은 어떻게 정하는가? 한쪽이 연결이 끊기면 재접속을 허용하는가, 방을 종료하는가?

참고: 방 상태는 메모리에만 있으므로 파드가 재시작되면 방이 사라진다 ([서버 상태·덱 저장소 구성](server-state-storage.md)).

## Blocked by

(없음)

## Resolution

사용자 결정 (2026-11-11):
- 방 만들기: 방을 만들면 짧은 방 코드(예: 4자리)와 초대 링크(`/r/<코드>`)가 발급된다.
- 입장: 초대 링크를 열거나, 첫 화면에서 방 코드를 입력해 들어온다. 방은 2인 정원이고, 가득 찬 방에는 입장할 수 없다.
- 닉네임: 입장할 때 닉네임을 입력한다. DM 화면에서 보낸 사람 이름으로 표시된다.
- 선공: 방을 만든 사람이 첫 DM을 보내고, 이후 라운드마다 역할을 교대한다.
- 재접속: 브라우저에 저장한 플레이어 토큰으로 일정 시간(기본 5분) 안에 돌아오면 이어서 한다. 그동안 상대에게는 '연결 끊김'이 표시된다. 시간이 지나면 방이 종료된다. 파드가 재시작되면 방은 사라진다.
